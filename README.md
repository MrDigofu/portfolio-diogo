
# Portfólio Pessoal - Diogo Ravanelli

**Aluno:** Diogo Fujita Machado Neves Ravanelli

## Descrição
Portfólio pessoal desenvolvido para apresentar meu perfil,
habilidades, projetos e informações de contato.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Link do site
https://SEU-USUARIO.github.io/portfolio-diogo/

## Funcionamento
O site possui menu de navegação para acessar as seções
Perfil, Habilidades, Projetos e Contato.

O Bootstrap foi utilizado para criar o layout responsivo.

## Recurso novo adicionado
Foi implementada uma animação nas barras de progresso
da seção Habilidades.

## Como foi implementado
Foi utilizada a API IntersectionObserver do JavaScript
para detectar quando as barras aparecem na tela.

A propriedade transition do CSS cria o efeito de
preenchimento gradual das barras.

## Publicação
O projeto será publicado utilizando GitHub Pages.
